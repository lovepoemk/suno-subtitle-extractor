# Suno Subtitle Extractor

Unofficial Chrome extension for inspecting, adjusting, and exporting Suno-provided aligned lyrics.

## Features
- Export YouTube-ready SRT subtitles
- Export LRC timed lyrics
- Export the original aligned JSON response
- Preview aligned lyric timing before export
- Optional overlap trimming for SRT
- Manual cue insertion for short lines Suno's alignment omitted
- Korean and English UI
- No analytics, ads, telemetry, developer backend, or persistent storage

## Privacy
Privacy policy: https://lovepoemk.github.io/suno-subtitle-extractor/privacy-policy.html

## Notes
- This tool is unofficial and is not affiliated with Suno.
- It relies on Suno's current website/internal API behavior and may require updates if Suno changes its systems.
- Only export content you are authorized to access and use.
