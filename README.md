# Suno Subtitle Extractor

Unofficial Chrome extension for inspecting, synchronizing, editing, and exporting Suno-provided aligned lyrics.

## Features
- Single Chrome Side Panel interface
- Live five-line subtitle view following Suno playback
- Keeps the current subtitle near the center with upcoming lines visible
- Cue text/timing editing, deletion, reset, and missing-cue insertion
- Global subtitle sync adjustment
- YouTube Ready cleanup preset
- Optional structure-tag removal
- Export SRT, VTT, LRC, TXT, and raw aligned JSON
- 12 UI languages with automatic detection and manual selection
- Side Panel enabled only on supported Suno song tabs

## Privacy
Privacy policy: https://lovepoemk.github.io/suno-subtitle-extractor/privacy-policy.html

The extension has no analytics, ads, telemetry, developer-operated backend, or persistent extension storage. Suno authentication is used only inside the Suno page for the user-requested direct aligned-lyrics request to Suno.

## Notes
- This tool is unofficial and is not affiliated with Suno.
- It relies on Suno's current website/internal API behavior and may require updates if Suno changes its systems.
- If playback has not initialized, start the song once on the Suno page.
- Only access and export content you are authorized to use.
