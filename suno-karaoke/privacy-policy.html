Privacy Policy — Suno Karaoke

Effective date: September 19, 2026

Suno Karaoke is an unofficial Chrome extension and is not affiliated with, endorsed by, or sponsored by Suno.

Purpose

The extension provides karaoke-style lyric display, practice controls, microphone features, local voice recording, and a local song/recording library for individual Suno song pages.

Site access

The extension requests host access only to https://suno.com/* and https://www.suno.com/*. It does not request access to unrelated websites.

Data handled

Current Suno page

The extension reads the current Suno song URL and page title to identify the selected song and to save a local library link.

Suno authentication

When aligned lyrics are requested, packaged extension code running inside the Suno page temporarily reads the page's existing Suno session value to authenticate a direct request to Suno's own aligned-lyrics API. The session value is not stored, logged, displayed, downloaded, or sent to the developer.

Lyrics, timing, waveform, and playback state

The extension processes lyric text, timing data, word alignment data, waveform data, and current playback state returned or exposed by Suno. These are used for lyric synchronization, countdowns, lyric progress coloring, practice controls, and the music-reactive visualizer.

Microphone

Microphone access occurs only after the user explicitly requests it and grants Chrome permission. Microphone audio is processed locally for input monitoring, level display, and user-requested recording. Microphone audio is not transmitted to the developer.

Recordings and library

User-created microphone recordings and saved-song library entries are stored locally in the browser using IndexedDB. Practice preferences such as per-song sync adjustment are stored locally by the extension.

Storage and retention

The developer does not operate a backend that stores extension data. Local recordings and library data remain on the user's browser profile until the user deletes them or clears the extension/browser data. Removing the browser profile or clearing extension data may permanently remove locally stored recordings and library entries.

Sharing

The developer does not receive, sell, rent, or share user data.

Analytics, advertising, and tracking

The extension contains no analytics SDK, advertising system, tracking pixel, telemetry, or developer-operated backend service.

Security

Network requests used for the aligned-lyrics feature use HTTPS. Authentication information is not intentionally written to logs, persistent storage, exported files, or developer servers.

Chrome Web Store Limited Use

Data is used only to provide the disclosed extension functionality and is not used for advertising, profiling, credit decisions, data brokerage, or unrelated purposes.

Suno dependency

The extension depends on Suno's current website and data behavior. Suno changes may temporarily affect extension functionality.

Contact

For privacy or support questions, use the developer contact shown on the Chrome Web Store listing.
