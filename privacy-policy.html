Privacy Policy — Suno Subtitle Extractor

Effective date: September 18, 2026

Suno Subtitle Extractor is an unofficial browser extension. It is not affiliated with, endorsed by, or sponsored by Suno.

Single purpose

The extension's single purpose is to let users inspect, make small subtitle adjustments to, and export Suno-provided time-aligned lyrics for the currently open Suno song as SRT, LRC, or JSON files.

Data the extension handles

When the user opens the extension on a Suno song page, it reads the current tab's URL and title to identify the selected song and create a filename. The extension does not collect general browsing history.

Only after the user clicks Load aligned lyrics, a packaged script runs inside the current Suno page. That script temporarily reads Suno's __session authentication cookie and uses it to request the selected song's aligned-lyrics data directly from Suno's own API over HTTPS.

The aligned-lyrics response may include lyric text, timing data, section information, word-level alignment information, waveform data, and other metadata returned by Suno.

How data is used

The authentication value is used only to authenticate the direct request to Suno. It is not logged, stored, exported, displayed, or sent to the extension developer.

The returned aligned-lyrics data is processed locally in the browser only to display a preview, apply user-selected subtitle adjustments, and create files that the user explicitly downloads.

Storage and retention

The extension does not use persistent extension storage. Aligned-lyrics data and manually added subtitle cues remain in memory only while the popup is open. Files explicitly downloaded by the user are stored wherever the user's browser saves downloads.

Sharing and third parties

The developer does not receive, sell, rent, or share user data. The network request required for the extension's core function is made directly from the Suno page to Suno's own API. Suno's handling of data is governed by Suno's own terms and privacy policy.

Analytics, advertising, and tracking

The extension contains no analytics, advertising SDKs, tracking pixels, telemetry, or developer-operated backend service.

Security

Requests are made over HTTPS. Authentication information is never intentionally written to logs, persistent storage, download files, or developer servers.

Chrome Web Store Limited Use

The extension uses data only as necessary to provide its disclosed single purpose. It does not use user data for advertising, credit decisions, data brokerage, profiling, or unrelated purposes.

Changes

If the extension's data practices materially change, this policy and the Chrome Web Store disclosures will be updated before the changed practices are released.

Contact

For privacy or support questions, use the developer support contact shown on the Chrome Web Store listing.
