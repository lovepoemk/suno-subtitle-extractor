Privacy Policy — Suno Subtitle Extractor

Effective date: September 19, 2026

Suno Subtitle Extractor is an unofficial browser extension. It is not affiliated with, endorsed by, or sponsored by Suno.

Single purpose

The extension's single purpose is to let users inspect, synchronize, make subtitle adjustments to, and export Suno-provided time-aligned lyrics for the currently selected Suno song as SRT, VTT, LRC, TXT, or JSON.

Site access

The extension is limited to suno.com and www.suno.com. Its Side Panel is enabled only for supported individual Suno song pages. It does not request access to unrelated websites.

Data the extension handles

The extension reads the current Suno song URL and title only to identify the selected song and create filenames.

Only after the user clicks Load aligned lyrics, a packaged script running inside the Suno page temporarily reads Suno's __session authentication value and uses it to request the selected song's aligned-lyrics data directly from Suno's own API over HTTPS.

The aligned-lyrics response may include lyric text, timing data, section information, word-level alignment information, waveform data, and other metadata returned by Suno.

For Live Sync Preview, the extension may read the current Suno player's playback time, duration, and play/pause state. It also processes subtitle text and timing edits entered by the user.

How data is used

The authentication value is used only inside the Suno page to authenticate the direct request to Suno. It is not logged, stored, displayed, exported, or sent to the extension developer.

Aligned-lyrics data, playback state, and user edits are processed locally in the browser only to provide live subtitle synchronization, editing, preview, and files that the user explicitly exports.

Storage and retention

The extension does not use persistent extension storage. Aligned lyrics, playback state, and subtitle edits remain in memory while the Side Panel is active. Files explicitly exported by the user are stored wherever the browser saves downloads.

Sharing and third parties

The developer does not receive, sell, rent, or share user data. The extension has no developer-operated backend. Requests required for the core aligned-lyrics feature are made directly from the Suno page to Suno's own API. Suno's handling of data is governed by Suno's own terms and privacy policy.

Analytics, advertising, and tracking

The extension contains no analytics, advertising SDKs, tracking pixels, telemetry, or developer-operated backend service.

Security

Requests are made over HTTPS. Authentication information is never intentionally written to logs, persistent storage, exported files, or developer servers.

Chrome Web Store Limited Use

The extension uses data only as necessary to provide its disclosed single purpose. It does not use user data for advertising, credit decisions, data brokerage, profiling, or unrelated purposes.

Changes

If the extension's data practices materially change, this policy and the Chrome Web Store disclosures will be updated before the changed practices are released.

Contact

For privacy or support questions, use the developer support contact shown on the Chrome Web Store listing.
